# Submission docs

Подготовлены материалы для заявки и жюри SafeTransfer. Изменена только документация; приложение, веса риска, зависимости и lockfile не менялись.

## Материалы

- **README.md:** русская подача с коротким казахским слоганом, проблема/решение, возможности двух экранов, Mermaid-архитектура, реальные веса и пороги из `RISK_CONFIG`, устройство шаблонных объяснений, технологический стек, проверенные команды, ограничения, масштабирование и четыре места для скриншотов.
- **docs/DEMO_SCRIPT.md:** показ на три минуты с точными видимыми кнопками, фразами ведущего, подготовкой двух вкладок и запасными действиями; отдельный пятиминутный питч с двухминутным демо внутри.
- **docs/QA_FOR_JURY.md:** 12 ответов о точности/ложных тревогах, AI, SMS, приватности, масштабировании, интеграции, регулировании, объяснениях, отказах/подмене данных, весах и следующем пилоте.
- **docs/PROGRESS.md:** завершённая секция Docs с отдельными коммитами и результатами проверок.

Везде явно разделены действующие правила и шаблоны от будущих ML/LLM-возможностей. Баллы не названы вероятностями, синтетические сценарии — измерением точности, а сумма held/blocked — доказанными предотвращёнными потерями. Описаны отправка демо-параметров в собственный API, ограничения localStorage и отсутствие реального банковского контура.

## Ручная проверка перед подачей

1. Прочитать README как член жюри: ясны проблема, работающий MVP и граница между реализованным и будущим.
2. Сверить веса/условия с `web/lib/risk-engine.ts`, результаты и видимые названия с `demo-scenarios.ts` / `i18n.ts`.
3. Из корня выполнить `cd web`, `npm install`, `npm run lint`, `npm test`, `npm run build`; для показа — `npm run dev` и http://localhost:3000.
4. Пройти трёхминутный сценарий в RU с заранее открытой панелью банка на том же origin, затем переключить KK.
5. Проверить, что пятиминутный питч использует сокращённую двухминутную демонстрацию, а не добавляет полный трёхминутный показ сверх лимита.
6. Просмотреть 12 ответов; не добавлять неподтверждённые проценты точности, SLA, экономию или утверждение о соблюдении нормативов.
7. Перед фактической отправкой заменить четыре места в README реальными изображениями демо. Сейчас это намеренные placeholders, не приложенные скриншоты.
